# packages/ui

앱 화면 (React). 모든 기기 공용. B안 디자인.

WP1은 제목과 브라우저 진단 화면만 제공합니다. B안 토큰은 `src/style.css`에 CSS 변수로
정의하며 Noto Sans KR 네 가지 굵기는 앱에 포함합니다. 외부 폰트 서버에 연결하지 않습니다.
화면은 코어의 `/ui/`에서 제공하며 같은 출처의 `/ui-socket`으로 진단을 요청합니다.

WP3은 골투 로그인·권한 안내, 상품 검색·더 보기, 채널별 확인·등록 옵션,
진행·멈춤·이어하기, 서비스 로그인 자리, 기록과 관리자 설정을 제공합니다.
React 상태와 `src/store.ts` 하나를 사용하며 API 토큰과 비밀번호를 브라우저 저장소에 넣지 않습니다.
화면 이동은 History API로 처리하므로 브라우저·Android 뒤로 가기가 같은 순서를 따릅니다.
선택 옵션은 모두 꺼짐, 등록 방식은 임시저장이 기본입니다. 발행은 별도 확인 화면을 거칩니다.

루트에서 `pnpm sim`을 실행하면 기존 Chromium의 새 프로필에서 390×844 앱을 엽니다.
Ctrl+C로 종료합니다. `pnpm sim:check`는 주요 흐름과 WP1 진단을 headless로 검사하고,
`pnpm sim:shots`는 같은 검사와 함께 검토용 PNG 11개를 `docs/reports/wp3/`에 저장합니다.
시뮬레이터는 localhost만 허용하며 실제 서비스 요청을 차단합니다.
