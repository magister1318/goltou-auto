# WP0 예시 그림

`sample-1.png`부터 `sample-4.png`는 320×180, `sample-5.png`는 180×320으로 직접 만든 도형 PNG다.
`node scripts/make-fixtures.mjs`로 원본을 재현한다. 리사이즈하지 않는다.
WP6 2차부터 다섯 번째 원본을 세로형으로 만들어 밴드의 고정 정사각 썸네일을 판별한다.
원본 비율까지 모두 같으면 이 신호를 사용 불가로 추정하지 않고 비율 불일치로 멈춘다.
실제 상품·골프장·인물·외부 사진이 아니다. 각 그림의 색과 도형 배치가 다르다.
실험은 이 다섯 파일만 앱 내장 번들에서 첨부하며 휴대폰 사진첩을 열지 않는다.
