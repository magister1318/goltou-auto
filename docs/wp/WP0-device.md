# WP0. 실기기 실험 (앱 기동, 블로그 긴 글, 밴드 글쓰기)

브랜치 `codex/wp0-device` (`origin/main`에서). 먼저 `AGENTS.md`, `docs/PRD.md`, `docs/reports/WP1.md`, `docs/reports/WP3.md`를 읽습니다.

폰: 갤럭시 S24 울트라(SM-S928N)가 이 PC에 USB 디버깅으로 연결되어 있습니다. `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`를 씁니다. 폰은 사용자의 실제 폰입니다. **골투오토 앱(`kr.goltou.auto`) 밖의 것은 건드리지 않습니다**: 다른 앱 실행·삭제·설정 변경·파일 열람 금지, `adb shell`은 이 앱의 설치·실행·로그(`logcat`은 이 앱 프로세스만 걸러서)·화면 캡처·`run-as kr.goltou.auto`에만 씁니다. 화면 캡처는 골투오토가 앞에 떠 있을 때만 찍습니다.

## 목적

코딩을 더 하기 전에, 아래가 이 폰에서 실제로 되는지 확인하고 안 되는 것을 찾습니다. 결과가 제품 설계를 정합니다.

## 1단계. 로그인 없이 확인 (이번 실행에서 끝까지)

1. main의 디버그 APK를 빌드해 설치·실행.
2. 내장 Node(nodejs-mobile 18.20.4)가 뜨고 화면(WP3 UI, 가짜 데이터)이 열리는지. 기동 시간.
3. 설정 > 진단: 숨김 WebView가 `https://example.com/`을 열어 제목을 읽는지(DevTools 중계 포함).
4. WebView 버전, `MULTI_PROFILE`·`DELETE_BROWSING_DATA` 지원 여부, 세션 3개(네이버·밴드·AI) 프로필 분리.
5. 숨김 Surface 보이기/숨기기, 앱을 뒤로 보냈다 돌아오기, 화면 회전·Activity 재생성 뒤에도 core 연결이 유지되는지.
6. 안 되는 것은 고칩니다(껍데기 Kotlin·bridge·core 범위). 고친 내용과 원인을 보고서에 적습니다.

## 2단계. 실험 도구 만들기 (이번 실행에서 만들고 설치까지)

설정 화면 아래에 디버그 빌드에서만 보이는 '실험' 화면을 만듭니다. 실제 등록 기능이 아니라 실험용입니다.

- **로그인 화면 열기**: 네이버(`https://nid.naver.com/nidlogin.login`), 밴드(`https://auth.band.us/login`)를 각 세션의 Surface로 보이게 열고 닫기. 사용자가 직접 로그인합니다. 앱은 입력값을 읽거나 저장하지 않습니다.
- **로그인 상태 확인**: 네이버·밴드 각각 로그인됨 / 풀림 / 모름을 읽기 전용으로 판단(DAF `daf3/modules/helper`의 로그인 확인 방식 참고).
- **블로그 실험**: 데스크톱 UA, 1280×900 숨김 Surface로 블로그 글쓰기를 열고, 예시 상품 글(제목 + 본문 3,000자 이상, 문단 15개 이상, 사진 5장: 저장소에 넣은 예시 PNG, 실제 상품 아님)을 사람 속도로 입력 → **임시저장** → 임시저장 목록에서 다시 읽어 제목·글자 수·사진 수 대조. DAF의 네이버 편집기 입력 코드를 `packages/sites/naver-blog`로 필요한 만큼만 옮깁니다. 발행 버튼은 누르지 않습니다.
- **밴드 실험**: 밴드 목록 읽기(이름·식별키), 사용자가 고른 밴드의 글쓰기 열기, 같은 예시 글과 사진 5장 넣기. golfliat `fillBandComposerInWebview`를 참고하되 AGENTS.md 원칙대로 입력 명령으로만 조작합니다. 확인할 것: 모바일 UA와 데스크톱 UA 중 어느 쪽이 되는지, 사진 첨부 방법(파일 입력 / 붙여넣기), 글자 수 한도, **밴드에 임시저장이 있는지와 그 동작**. 임시저장이 없으면 게시 버튼 바로 앞에서 멈추고 화면을 캡처한 뒤 글쓰기를 닫습니다. **밴드에 실제로 게시하지 않습니다.**
- 각 실험은 단계별 기록(시각, 한 일, 결과, 걸린 시간, 실패 시 화면 캡처와 DOM 요약)을 앱 전용 폴더에 JSON으로 남기고, `adb`로 꺼내는 스크립트 `pnpm device:pull`을 둡니다. 기록에 쿠키·토큰·계정 아이디·비밀번호를 넣지 않습니다.
- 로그인이 필요한 실험은 이번 실행에서 돌리지 않습니다. 설치까지 하고, 로그인 상태 확인이 '풀림'으로 나오는 것까지만 확인합니다.

## 3단계 (다음 실행, 사용자가 로그인한 뒤)

사용자가 폰의 실험 화면에서 네이버·밴드에 로그인하면 Claude가 다시 지시합니다. 그때 블로그·밴드 실험을 돌리고, 선택자와 대기 조건을 고치며 반복합니다.

## 끝내는 기준 (이번 실행)

- `pnpm install && pnpm typecheck && pnpm test`, `./gradlew assembleDebug` 통과.
- 1단계 항목별 결과(됨 / 안 됨 / 고침)와 2단계 도구 설치 확인을 `docs/reports/WP0.md`에. 화면 캡처는 `docs/reports/wp0/`(골투오토 화면만, 개인정보 없는 것만).
- 앱은 폰에 설치된 채로 두고, 실험 화면에 들어가는 방법을 보고서 맨 위에 적습니다.
- 초안 PR.
