  차단기를 유지하고 debug 허용 파일을 배포본 조건으로 쓰지 않는다. WP20 로그와 adb 없는

  게이트의 `install -r`와 부팅 확인을 허용한다. 삭제·초기화·서명 오류 우회는 금지한다.

  꼬리말을 남기며 모델 이름은 쓰지 않는다.
