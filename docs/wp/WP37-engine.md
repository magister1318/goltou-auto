# WP37 골투오토 1.0.5 엔진과 데이터

`codex/v105`에서 WP38 화면 작업에 넘길 엔진과 데이터 계약을 구현한다. 상품 한 건을 옮기는 기존 흐름에서 블로그를 먼저 처리하고 고른 밴드를 하나씩 처리한다.

- 장애 37에서 재현한 SmartEditor의 목록 자동 변환을 피한다. 키보드 입력과 읽기 전용 관찰로 번호·목록·인용 표식을 확인한다. 원 HTML의 글자와 미리 서식이 지정된 공백을 보존한다.
- 블로그 입력, 저장 전후, 다시 열기, 발행 확인과 밴드 작성·게시 확인에 같은 텍스트 허용 기준을 쓴다. 공백과 줄바꿈 변화는 허용한다. 글자 차이는 문단당 3자와 전체 1% 이내이면 허용으로 기록한다. 굵기와 그 외 비필수 글자 차이는 진단으로 남긴다. 가격·날짜 숫자, 링크 주소, 문단 누락, 사진 수·순서는 다시 읽어 확인한다.
- 실패 또는 미확정 기록에는 해당 작업의 코드와 수치만 담은 로그를 올린다. 최신 512KB를 전송하고, 연결 오류는 한 번 다시 시도한다. 구서버의 경로 부재를 허용한다.
- 국가, 지역, 골프장, 설정의 태그 단어를 순서대로 정리해 블로그 태그 필드와 밴드 본문 마지막 줄에 반영한다. 미리보기에 태그 유형을 제공한다.
- `/auto/me`의 개인 문구와 닉네임·휴대폰 치환을 적용한다. 이번 작업의 끝 문구 스위치는 개인 기본값에서 시작한다. 개인 문구 저장 명령과 상품 담당자·변경 여부·게시 이력의 선택 필드를 추가한다.
- 대상별 기록과 로그, 밴드 사이 20~40초 대기, 오늘 한도 사전 확인, 마지막 밴드 목록 이관, 실패한 대상만 다시 시도하는 명령을 제공한다.
- 합성 편집기와 로컬 API에서 검증한다. Android 버전은 `1.0.5 (9)`다.

계약과 장애 기록은 작업 폴더 상위 `runs/v105-contract.md`, `runs/diag37-report.md`에 있다.
