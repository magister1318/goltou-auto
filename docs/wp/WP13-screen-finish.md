# WP13 화면 마무리

이번 사용자 지시가 범위다. 최신 `origin/main`을 가져와 `codex/screen-finish`에서 작업한다.

- B안의 초록색, 글 중심 목록, 여백·글자·44px 누름 영역을 지킨다. 카드·그림자·왼쪽 색 띠를 추가하지 않는다.
- 상품 목록과 미리보기에 API 사진을 표시한다. 기존 골투 HTTPS 호스트 제한을 함께 쓰고 Android CSP·자산 허용도 확인한다. 실패하면 중립 자리로 바꾼다.
- 미리보기는 사진 순서·위치·번호를 보여 주며 가까운 사진만 불러온다. 원본 첨부와 등록 엔진은 바꾸지 않는다.
- 초록 바탕과 흰 골프·전송 표시로 adaptive·round·monochrome 벡터 아이콘을 만들고 머리 부분에도 쓴다.
- 골투·네이버·밴드 로그인 안내와 상태 표시를 마무리한다. AI를 로그인 목록에서 빼고 문장 다듬기 안에만 화면 열기를 둔다.
- 로그인·상품·미리보기·진행·재로그인·기록·설정의 빈 화면·로딩·오류와 긴 글 줄바꿈을 확인한다.
- 사진 표시·호스트 제한·실패 자리·서비스 목록을 시험한다. install/typecheck/test/build와 Android assembleDebug를 확인한다.
- adb 연결, 화면 켜짐, 앱 앞 화면 조건을 읽기만 해서 확인한다. 조건이 맞을 때만 갱신 설치와 앱 내부 화면 캡처를 한다. 깨우기·잠금 해제·앱 밖 조작·작업 시작·임시저장·발행은 하지 않는다.
- 조건이 맞지 않으면 기기를 건드리지 않고 시뮬레이터로 캡처한다. PNG는 저장소 밖 `../runs/wp13-shots/`에 둔다.
- 짧은 한국어 보고서와 WP 목록을 갱신하고 커밋·푸시 후 `WP13: screen finish` 초안 PR을 연다. 실제 상품·계정·인증 정보와 화면 사진은 커밋하지 않는다.
