# WP14. 발행 방식과 비공개 한 건 확인

이번 사용자 지시가 작업 범위다. 최신 `origin/main`에서 `codex/publish-mode`로 작업한다.

- 블로그 발행의 공개 범위(`public` 기본, `private`)를 실행기까지 전달한다. 최종 버튼 직전 화면 선택과 CDP 요청을 검사하고 모르면 차단한다. 임시저장 안전장치는 유지한다.
- 발행 결과를 다시 읽어 원문·사진·숫자를 대조한 뒤 같은 API 기록에 `published`와 최종 주소를 기록한다.
- 일반 화면에 공개 범위와 시작 전 확인을 표시한다. 디버그 삭제는 이번 작업의 반환 글 ID와 `[골투오토 실험]` 접두사만 허용한다. 릴리스에 삭제 기능을 넣지 않는다.
- 실기기는 화면 켜짐·골투오토 전면을 교차 확인할 때만 설치·입력한다. 깨우기·잠금 해제·다른 앱 조작은 하지 않는다.
- 실제 상품 한 개로 **비공개 발행 한 번만** 허용한다. 확인 뒤 그 한 글만 즉시 삭제한다. 안전장치 실패·불확실·삭제 실패는 중단하며 재발행하지 않는다. 밴드와 기존 실험 임시글 네 개는 건드리지 않는다.
- `pnpm install`, `pnpm -r typecheck`, `pnpm typecheck`, `pnpm test`, `pnpm build`, Android `assembleDebug`를 확인한다.
- 한국어 보고서 `docs/reports/WP14-publish.md`와 목록을 갱신하고 커밋·푸시·초안 PR을 만든다. 실제 상품 내용·계정·글 주소·인증 자료는 저장소에 남기지 않는다.

실제 계정 발행 금지 규칙의 예외는 위 비공개 글 한 건과 그 삭제에 한정한다. 운영 서버 변경·DB 직접 연결은 허용하지 않는다.
