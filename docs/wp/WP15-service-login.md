# WP15. 서비스 로그인 실제 동작

이번 사용자 지시를 작업 지시서로 기록한다. `origin/main`에서 `codex/service-login`을 만든다. 화면 개편은 범위 밖이다.

- 작업이 없어도 네이버·밴드 영구 프로필의 로그인 화면을 만들고, 실제 로딩 뒤에만 연다. 실패는 오류와 재시도로 알린다.
- 로그인 표시를 읽기 전용으로 주기적으로 확인하고, 성공하면 자동으로 숨기고 확인됨으로 바꾼다. 돌아가기는 취소이며 숨긴 뒤 한 번 재확인한다.
- 시작·골투 로그인·오래 뒤 전면 복귀 때 두 서비스를 숨겨서 차례로 확인한다. 확인 중 상태를 표시한다. 작업과 겹치지 않는다.
- 인증 주소와 숨김 확인 주소만 허용한다. 편집기·밴드 피드·외부 링크·앱 링크·새 창을 차단한다. 로그인 화면 중에는 새 작업을 시작하지 못한다. 작업 중 열기는 login_paused에서만 허용한다.
- 자격증명·쿠키를 읽거나 저장하거나 입력하지 않는다. 실제 서비스 페이지에서는 로그인 표시만 읽는다.
- 단위·브라우저 fixture 시험과 pnpm install, pnpm -r typecheck, pnpm typecheck, pnpm test, pnpm build, Android assembleDebug를 통과한다.
- 연결·켜진 화면·앱 전면을 두 읽기 신호로 확인한 경우에만 adb install -r로 설치한다. 자동 상태 확인과 이미 로그인된 두 서비스 안내를 확인한다. 로그아웃·프로필 삭제·자격증명 입력·작업 실행은 금지한다. 미로그인은 fixture로만 시험한다.
- 한국어 보고서 `docs/reports/WP15-service-login.md`, 작업 목록 갱신, 커밋·푸시, main 대상 초안 PR `WP15: service login works on demand`를 남긴다.
