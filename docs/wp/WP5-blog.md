# WP5. 블로그 등록 전 과정

브랜치 `codex/wp5-blog`. **`codex/wp4-convert`에서 갈라 나옵니다**(PR #4가 아직 main에 없습니다). 초안 PR 대상도 `codex/wp4-convert`. 먼저 `AGENTS.md`, `docs/PRD.md`, `docs/reports/WP0.md`(3단계 결과 (블로그)와 WP5 권고), `docs/reports/WP4.md`를 읽습니다.

## 목표

가짜 실행기의 '블로그에 쓰기', '블로그 임시저장과 확인' 단계를 실제 동작으로 바꿉니다. 상품 데이터는 아직 가짜 API의 예시 상품입니다(골투 서버 연결 없음). 네이버 쪽은 실제입니다.

## 할 일

1. `packages/sites/naver-blog` 실제 실행기
   - 입력: WP4의 `InputPlan`(블로그용)과 준비된 사진 파일 매핑. 계획의 순서대로 글자, 줄바꿈, **사진 묶음을 그 자리에서**, 표를 넣습니다. WP0에서 한꺼번에 넣은 사진은 모두 끝에 붙었으므로, 사진 단계마다 커서가 그 자리에 있는지 확인하고 넣습니다.
   - 표(출발일·가격)는 편집기의 표 기능으로 넣습니다. 표 입력이 불안정하면 줄 목록 글자로 넣는 대안을 두고, 어느 쪽을 썼는지 기록합니다.
   - 선택 옵션: 끝 문구(글자), 해시태그(편집기 태그 칸), 골투 링크 카드(주소를 넣고 편집기가 만드는 링크 카드가 생겼는지 확인, 안 생기면 주소 글자로 남김). 모두 꺼짐이 기본.
   - 입력은 글자당 간격을 둔 입력 명령으로만. 32자마다 로그인·편집기 유지 확인(WP0 방식). DOM 쓰기 금지.
2. 저장과 확인
   - 임시저장 모드: 저장 1회 → 새 편집기에서 임시저장 목록의 정확한 제목 1건을 다시 열어 `Observation`으로 읽고 WP4의 공통 비교 함수로 대조(제목, 글자, 문단 수, 사진 수·순서, 가격·출발일 값). 일치해야만 `draft_saved`.
   - 저장 응답이 모호하면 다시 저장하지 말고 먼저 목록에서 제목을 확인합니다. 같은 제목이 둘이면 멈춥니다.
   - 발행 모드: 코드 경로는 만들되(임시저장·확인이 끝난 뒤 사용자가 그 작업에서 발행을 골랐을 때만 발행 → 발행된 글 주소 읽기 → `published`), **실기기와 실제 네이버에서는 절대 실행하지 않습니다.** 로컬 가짜 페이지 시험만.
3. 멈춤과 이어하기
   - 로그인 풀림 감지 → 작업을 '로그인 풀림으로 멈춤'으로 두고 화면이 네이버 로그인 Surface를 보여 줌 → 사용자가 로그인 후 '이어하기' → 편집기 상태를 다시 읽어, 이미 들어간 내용이 계획의 앞부분과 일치하면 그 뒤부터, 아니면 새 글로 처음부터.
   - 작성 중인 글 자동복구 안내: 사용자에게 물어보는 화면(이어서 쓰던 글을 버리고 새로 시작할지)을 만들고 동의했을 때만 거절합니다.
   - 편집기가 띄우는 기본 확인창(alert/confirm): 사용자에게 내용을 보여 주고 사용자가 고르게 합니다. 자동으로 누르지 않습니다. 필요한 껍데기 연결(WebChromeClient의 대화상자 전달)을 추가합니다.
   - 사용자가 멈추면 편집기를 닫지 않고 둡니다. 실패 시 단계, 이유, 마스킹 캡처를 기록에 남깁니다.
4. 화면 연결: 진행 화면의 단계·단계 안 진행(사진 3/5, 글자 %)·남은 시간 어림, 완료 뒤 기록 화면의 '확인하고 발행'(임시저장 글을 네이버 Surface로 보여 주기). B안 그대로.
5. 숨김 WebView 캡처의 좌표·배율 문제(WP0에서 채택 못 함)를 고쳐 마스킹 캡처가 맞게 나오게 합니다.
6. 시험: 로컬 가짜 편집기 페이지로 순서 입력, 사진 위치, 표, 저장 모호 응답, 중복 제목, 로그인 풀림 → 이어하기, 자동복구 동의/미동의, 확인창 전달, 발행 경로(가짜에서만).

## 실기기 확인 (폰 SM-S928N, 소유자가 네이버에 로그인해 둠)

- `kr.goltou.auto` 밖은 건드리지 않습니다. 로그인·로그아웃·자격 증명 입력 금지. 로그인이 풀려 있으면 그 사실을 보고하고 실기기 단계를 멈춥니다.
- **발행 금지.** 임시저장만, 이번 실행 전체에서 최대 3회. 제목은 `[골투오토 실험]`으로 시작. 만든 임시저장 글은 지우지 말고 보고서에 제목을 적습니다(삭제는 소유자 확인창이 필요).
- 예시 상품 하나(사진 5장 이상이 글 사이에 섞이고, 출발일·가격 표가 있는 것)로 앱의 실제 흐름(홈 → 확인 → 임시저장으로 등록 시작 → 진행 → 완료)을 돌립니다. 골투 로그인은 가짜 API 계정.
- 재열람 대조가 일치하는지, 사진이 원문 위치에 들어갔는지, 걸린 시간, 표 입력 방식.
- 밴드 글쓰기는 열지 않습니다.
