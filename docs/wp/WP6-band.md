# WP6. 밴드 등록 전 과정

브랜치 `codex/wp6-band`. **`codex/wp5-blog`에서 갈라 나옵니다**. 초안 PR 대상도 `codex/wp5-blog`. 먼저 `AGENTS.md`, `docs/PRD.md`, `docs/reports/WP0.md`(3단계 결과와 밴드 권고, 밴드 제품 결정), `docs/reports/WP4.md`, `docs/reports/WP5.md`를 읽습니다.

## 확정된 결정 (소유자)

- 밴드에는 임시저장이 없습니다. **임시저장 모드**에서는 글과 사진을 다 넣고 **게시 직전에 멈춘 뒤** 밴드 글쓰기 화면을 사용자에게 보여 줍니다. 게시 버튼은 사용자가 직접 누릅니다. 기록 상태는 `stopped_before_post`(화면 표시 '게시 전 멈춤')이며 저장된 임시글로 적지 않습니다.
- **발행 모드**에서만 앱이 게시 버튼을 누릅니다(사용자가 그 작업에서 발행을 골랐고 실행 전 확인을 한 경우).
- 기본 경로는 WP0 권고대로 모바일 UA + 파일 입력 첨부.

## 할 일

1. `packages/sites/band` 실제 실행기
   - 내 밴드 목록 읽기(이름·식별키, 광고·추천 제외) → 확인 화면의 '밴드 고르기'에 연결(여러 곳 선택 가능하되 **한 번에 한 밴드씩 순서대로**, 각 밴드가 기록 한 건).
   - 입력: WP4의 밴드용 `InputPlan`. 글자는 입력 명령으로, 사진은 파일 입력으로. 밴드는 사진이 글 사이가 아니라 묶음으로 붙으므로 계획의 사진 순서만 지킵니다. 사진 수가 밴드 한도를 넘으면 실행 전에 확인 화면에서 알립니다(한도는 실행 중 관측값으로 기록, 추측으로 자르지 않음).
   - 입력 뒤 작성기에서 다시 읽어 글자(공백 정리)·사진 수·순서를 `Observation`으로 대조. 일치해야 다음으로.
   - 임시저장 모드: 일치 확인 → 작성기 Surface를 사용자에게 보이게 전환 → '게시 전 멈춤'. 사용자가 밴드 화면에서 직접 게시하거나 닫습니다. 사용자가 게시했는지는 작성기가 닫히고 글 주소가 생겼는지 읽기 전용으로 확인해 `published`(주소 포함) 또는 그대로 `stopped_before_post`로 남깁니다. 사용자가 '버리기'를 고르면 작성 취소 확인 후 `stopped`.
   - 발행 모드: 일치 확인 → 게시 버튼 1회 → 게시된 글을 다시 읽어 대조 → `published`. **이 경로는 실기기와 실제 밴드에서 실행하지 않습니다(로컬 가짜 페이지 시험만).**
   - 하루 한도: `/auto/posts/start`가 `conflict`를 주면 그 밴드는 시작하지 않고 이유를 보여 줍니다(가짜 API에 같은 동작).
2. 멈춤과 이어하기: 로그인 풀림 → 밴드 로그인 Surface → 이어하기(작성기가 살아 있고 앞부분이 일치하면 이어서, 아니면 처음부터). 기본 확인창은 WP5의 전달 방식을 그대로 씁니다. 다른 탭·창으로 새 글쓰기를 열지 않습니다.
3. 블로그와 밴드를 함께 고른 작업: 블로그 단계가 끝난 뒤 밴드 단계. 블로그가 실패해도 밴드는 사용자가 고르면 진행할 수 있게(기록은 채널별).
4. 화면: 진행 화면의 밴드 단계, '게시 전 멈춤' 상태에서 '밴드 화면 보기' / '버리기', 기록 화면의 채널별 상태 문구('게시 전 멈춤 · 확인하고 게시', '게시 완료', '실패'). B안 그대로.
5. 시험: 로컬 가짜 밴드 페이지(모바일·데스크톱 구조)로 목록, 입력, 사진 순서, 대조 불일치 차단, 게시 전 멈춤, 사용자 게시 감지, 버리기, 발행 경로(가짜에서만), 하루 한도, 로그인 풀림.

## 실기기 확인 (폰 SM-S928N, 소유자가 밴드에 로그인해 둠)

- `kr.goltou.auto` 밖은 건드리지 않습니다. 앱이 전면에 있고 화면이 켜져 있는 것을 읽기 전용으로 확인하지 못하면 기기 단계를 건너뛰고 보고합니다. 잠금 해제 시도 금지.
- **게시 금지.** 게시 버튼은 누르지 않습니다. 작성기 열기는 이번 실행 전체에서 최대 3회, 내 밴드 목록의 첫 밴드만. 예시 상품 하나로 앱의 실제 흐름(홈 → 확인 → 밴드만 선택, 임시저장으로 등록 시작 → 진행 → 게시 전 멈춤)을 돌리고, 대조 일치·사진 순서·걸린 시간을 기록한 뒤 '버리기'로 작성 내용을 폐기합니다.
- 계정·밴드 이름·식별키를 저장소에 남기지 않습니다(밴드 A로 표기, 캡처 마스킹).
- 네이버 편집기는 열지 않습니다. 골투 서버 연결 없음.
