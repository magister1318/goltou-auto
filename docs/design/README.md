# 화면 디자인 (B안 + 초록, 2026-11-12 확정)

시안 캔버스: https://claude.ai/artifact/UnSVhfVjDpeEUS5Eqvb1hP
`mockups/`의 `B_*.dc.html`은 그 시안의 원본 마크업입니다(캔버스 전용 형식이라 그대로 실행되지는 않습니다. 구조, 문구, 크기, 색을 읽는 용도입니다).

## 성격

글 중심 목록형. 흰 바탕에 큰 글자와 가는 줄. 카드, 그림자, 테두리 상자를 쓰지 않습니다. 선택은 스위치와 밑줄 글자로, 큰 버튼은 화면 맨 아래 가득 찬 막대 하나뿐입니다.

## 토큰

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| green-deep | `#0F5132` | 홈·기록 머리 부분 바탕, 아래 실행 막대, 굵은 구분선(2px), 선택된 글자 |

| green-on-dark | `#7BE0A0` | 짙은 초록 바탕 위의 정상 상태 점 |

| ink-2 | `#333333` | 긴 본문 |

| danger | `#A3231A` | 실패 |

- 글꼴: Noto Sans KR (400, 500, 700, 900). 화면 제목 30px/900, 상품 제목 17px/700, 본문 14~15px, 보조 13px.
- 좌우 여백 24px. 누르는 영역 높이 44px 이상.
- 아이콘은 선으로 된 SVG만, 이모지 금지.
- 색만으로 상태를 구분하지 않습니다(글자도 함께).
