# 직원 휴대폰 설치 안내

**WP30의 1.0.0 (2)는 서명 확인용 준비본입니다. 자동 등록이 동작하지 않아 배포를 보류합니다. 기존 앱을 유지하세요.**

담당자가 자동 등록을 검증한 배포본을 안내한 뒤 다음 순서로 설치합니다.

1. 담당자에게 받은 APK 파일을 휴대폰에서 엽니다.
2. 막히면 Android 안내의 ‘설정’에서 파일을 연 앱의 ‘이 출처 허용’을 켭니다.
   휴대폰에 따라 ‘알 수 없는 앱 설치’라는 이름일 수 있습니다.
3. 설치 또는 업데이트를 누르고 골투오토를 엽니다. 설정에서 안내받은 버전을 확인합니다.
4. 골투·네이버·밴드는 소유자가 직접 로그인합니다. 비밀번호를 담당자에게 보내지 않습니다.
5. 기본은 임시저장입니다. 발행은 해당 작업에서 직접 선택하고 최종 확인해야 합니다.
6. 문제는 설정 → 작업 로그 → ‘로그 내보내기’로 보관합니다. adb는 필요 없습니다.

**‘기존 앱과 충돌’ 또는 서명 오류가 나오면 멈추세요. 앱 삭제·데이터 지우기를 누르지 마세요.**
같은 배포 키의 정상 업데이트는 데이터를 유지합니다. 현재 debug 앱은 서명이 달라 그대로
업데이트할 수 없습니다. 담당자와 백업·전환 시점을 정해야 합니다.

전환 전에 담당자가 준비한 같은 서명의 백업 지원 앱에서 ‘데이터 내보내기’를 사용하고 로그도
별도로 내보냅니다. 새 앱의 ‘데이터 가져오기’는 글 옵션과 기록의 공개 범위·표 표시를 복구합니다.
등록 내역과 공통 설정은 같은 골투 계정으로 로그인하면 서버에서 읽습니다. 로그인 정보는 옮기지 않습니다.
백업과 새 앱의 실제 동작을 확인하기 전에는 기존 앱을 지우지 않습니다.
