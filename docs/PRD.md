# 골투오토 PRD (저장소용 요약)

원본 문서: https://claude.ai/artifact/UYZjtBVbgsD9QNPnD9bip9 (2026-11-12 사용자 확정). 둘이 다르면 원본이 기준이며, 이 파일을 원본에 맞춰 고칩니다.

## 무엇을 만드나

골투에 올라온 해외투어 상품을 고르면 네이버 블로그와 네이버 밴드에 같은 내용의 글을 대신 써 주는 안드로이드 앱 '골투오토'. 내부 전용이고 공개 배포하지 않으며, 한 번에 한 건씩 사람이 쓰는 속도로 등록한다.

### 소유자 추가 결정 (2026-11-13)

- 상품 본문의 취소선 글자는 블로그와 밴드 모두에 옮기지 않는다. `del`, `s`, `strike` 및 인라인 `text-decoration` / `text-decoration-line` 값에 `line-through`가 있는 요소의 하위 글자가 대상이며 중첩도 적용한다. 밴드가 취소선을 표시하지 못해 지난 가격·날짜가 유효한 정보처럼 보이는 것을 막기 위한 필수 규칙이다.
- 취소선 안의 사진은 원래 순서·위치에 남긴다. 글자를 빼서 빈 문단은 없애며, 제거 때문에 맞닿은 공백만 합친다. 가격·날짜·숫자 보존 대조에서도 제외한 본문 글자를 양쪽에서 빼고, API 가격·출발일은 그대로 보존한다.
- 확인 화면에는 `취소선 글자 N자는 옮기지 않습니다`라는 개수 안내만 표시하며 끄는 선택은 없다. 제거 글자 수는 HTML 엔티티를 해석한 원본 텍스트의 유니코드 코드포인트 수(공백 포함)이며 중첩 글자를 한 번만 센다. 제외 코드·메타데이터·속성은 세지 않는다. 변환 점검은 기존 취소선 숫자 지표와 함께 `droppedStruckCharacters`를 기록한다.

## 사용자와 권한

골투 회원 등급 `gf_user.user_type` 기준. 판단은 서버가 매 요청마다 한다.

| 등급 | 대상 | 할 수 있는 일 |
| --- | --- | --- |
| 0~2 | 일반 회원 | 사용 불가. 로그인 직후 안내 화면만 |
| 3~6 | 매니저 | 상품 보기, 본인 블로그·밴드에 등록, 본인 기록 보기 |
| 7 | 내부직원 | 매니저와 같음 + 전체 기록 보기 |
| 8·9 | 관리자 | 내부직원과 같음 + 공통 끝 문구, 기본 해시태그, 밴드 하루 상한 설정 |

네이버·밴드 세션은 휴대폰 안에만 있고 골투 서버로 보내지 않는다.

## 핵심 흐름

1. 홈 위쪽에 골투, 네이버 블로그, 밴드 로그인 상태. 풀린 것은 주황 표시와 '로그인하기'.
2. 상품 목록에서 검색, 국가·지역, 출발 월로 고른다. 내가 등록한 상품에는 채널별 등록일 표시. '안 올린 상품'만 보기.
3. 상품을 누르면 '옮길 내용 확인'. 블로그용/밴드용 탭, 원문 대조 결과(가격·출발일·사진 개수).
4. 등록 방식(임시저장/발행), 올릴 곳(블로그 카테고리, 밴드 여러 곳), 선택 옵션(문장 다듬기, 끝 문구, 링크 카드)을 고른다. 지난 선택을 기억한다.
5. '등록 시작' → 진행 화면. 7단계: 로그인 확인, 사진 내려받기, 본문 정리, 블로그에 쓰기, 블로그 임시저장과 확인, 밴드에 쓰기, 결과 기록.
6. 임시저장 방식이면 저장해 두고 멈춘다. 발행 방식이면 발행 버튼까지 누른다.
7. 등록 기록에 글 주소와 결과가 남는다. 실패는 어느 단계에서 왜 멈췄는지 한 줄, '다시 시도'.

로그인이 도중에 풀리면 그 단계에서 멈추고 로그인 화면을 보여 준다. 다시 로그인하면 멈춘 단계부터 잇고, 이미 저장된 글을 다시 쓰지 않는다. 네이버가 보호조치나 자동입력 방지 문자를 띄우면 그 화면을 사용자에게 보여 준다.

## 기능 요구사항

### 로그인

- 골투: 아이디·비밀번호를 사용자가 입력. 앱은 서버가 준 접속 토큰만 기기 보안 저장소에 둔다.
- 네이버, 밴드: 앱 안에 각 서비스의 로그인 화면을 그대로 띄우고 사용자가 로그인. 2단계 인증도 사용자가 처리.
- 상태 확인 시점: 앱을 열 때, 등록 시작 직전, 각 채널 작업 시작 때.
- 계정마다 로그아웃 버튼.

### 상품

- 판매 중인 해외투어만(`gf_is_comment = 0 AND gf_is_disable = 0`).
- 검색어, 국가·지역, 출발 월. 정렬은 최신순, 출발일 가까운 순.

### 변환과 AI Mode

| 항목 | 처리 |
| --- | --- |
| 가격, 출발일, 골프장 이름, 상품 주소 | 코드가 API 값 그대로 삽입 |
| 사진 | 원본 해상도로 내려받아 원문 순서대로 첨부 (리사이즈 금지) |
| 본문을 편집기용 덩어리(소제목, 문단, 표, 사진 자리)로 나누기 | 규칙 변환이 먼저, 애매한 부분만 AI Mode |
| 블로그 제목 후보, 해시태그 | AI Mode |
| 문장 다듬기(선택) | AI Mode가 소개 문단만 다시 씀. 숫자·일정표는 그대로 |

- 변환 뒤 원문과 대조: 가격·날짜 개수와 값, 사진 장수, 문단 누락. 다르면 등록을 막고 어디가 다른지 보여 준다.
- AI Mode가 응답하지 않거나 형식이 깨지면 한 번 재시도하고, 그래도 안 되면 규칙 변환 결과만으로 진행한다.

### 네이버 블로그

- PC용 편집기를 숨김 화면(1280×900)에서 열어 버튼·키보드·마우스 입력으로 작성.
- 제목, 본문 덩어리, 사진, 표, 해시태그, 카테고리. 끝 문구·링크 카드는 켰을 때만.
- 임시저장 후 다시 열어 제목·본문·사진 장수를 확인한 뒤에만 완료.
- 같은 상품을 다시 올리려 하면 이전 등록일과 주소를 보여 주고 확인받는다.

### 네이버 밴드

- 내 밴드 목록에서 올릴 밴드를 고른다(여러 곳이면 하나씩 차례로).
- 본문, 출발일별 가격, 사진. 끝 문구·링크 카드는 선택.
- 임시저장 방식: 밴드의 임시저장을 쓰고, 숨김 화면에서 쓸 수 없으면 입력을 마친 글쓰기 화면을 보여 주고 멈춘다(WP0에서 확인).
- 밴드당 하루 등록 수 상한(관리자 설정).

### 등록 기록

- 누가, 언제, 어느 상품을, 어느 채널에, 글 주소, 결과(완료·임시저장·실패·중단), 실패 단계와 이유.
- 등록 뒤 상품이 바뀌면 '등록 뒤에 골투 상품 가격이 바뀌었습니다' 표시.

### 1차에 하지 않는 것

아이폰·PC 앱, 예약 발행, 여러 상품 한꺼번에 등록, 댓글·이웃 관리, 다른 채널, 구글 플레이 등록, 국내투어.

## 기술 구조

- 안드로이드 껍데기(Kotlin): 숨김 WebView, DevTools 중계, 내장 Node(nodejs-mobile 18.20.4), 사진 전달. DAF `daf3/apps/mobile/android`에서 가져온다.
- 공용 코드(`packages/*`): 작업 순서, 사이트 조작 규칙, 화면, API 호출.
- 골투 API: goltou-hybrid `API`에 새 경로 `/auto/...` 추가. 계약은 `docs/api-contract.md`.
- 배포: 골투 매니저 전용 화면에서 APK 내려받기. 화면과 조작 규칙은 서명된 묶음으로 갱신(나중 WP).
- 대상: 안드로이드 11 이상.

| 기기 | 숨김 브라우저 조작 | 상태 |
| --- | --- | --- |
| 안드로이드 | 앱 안 WebView를 DevTools로 | DAF에서 검증. 1차 |
| 윈도우·맥 | Electron 숨김 창 | DAF PC 앱, golfliat 방식. 나중 |
| 아이폰 | WebView에 스크립트 주입 | 미검증. 나중, 별도 실험 필요 |
