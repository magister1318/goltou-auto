# WP22 승인된 밴드 한 건 검증과 삭제

시험 글은 남아 있지 않다. 앱이 피드와 원래 글 주소의 부재를 확인했고 등록 기록은 `삭제함`이다. 게시 작업의 원래 종료는 `failed/BAND_PUBLISHED_READBACK_MISMATCH` 한 줄이며, 이를 성공으로 바꾸거나 다시 게시하지 않았다.

## 실행 범위

- 2026-11-17 08:30 KST의 소유자 승인에 따라 이전 18:14 블로그 임시저장과 같은 판매 상품 한 건을 사용했다. 승인된 밴드만 선택하고 앱 계획을 그대로 입력했다. 문장 다듬기·글 끝 문구·링크 카드는 모두 꺼짐이다.
- 먼저 기기의 깨어 있음·잠금 해제·앱 포커스를 읽기만 했다. 깨우기·잠금 해제·기기 설정 변경·다른 앱 조작·네이버 조작·로그인 페이지 입력은 없었다.
- PR #23, #24 병합 뒤 `origin/main`을 가져와 `002dc1f`를 확인하고 해당 코드로 `assembleDebug`, `adb install -r`를 실행했다.
- 앱의 공유 밴드 프로필을 쓰는 목록/게시 WebView에서 잔여 시험 제목이 없음을 확인했다. 로그인 확인 WebView를 탐색에 쓰지 않았다.
- 최종 앱 발행 확인 직전에 일회 허용 파일을 한 번 만들었다. 앱의 입력·사진 확인이 끝난 뒤 실제 제출 직전에 한 번 소진됐고 실제 생성 요청은 한 건이다. 허용 결정과 네트워크 증거의 두 로그 줄을 두 번 제출한 것으로 세지 않았다.
- 일회 허용 파일 생성과 소비 각 1회, 앱 발행 시작 1회, 실제 생성 요청 허용 1회다. 생성 결정 줄과 동일 요청의 네트워크 증거 줄을 두 번의 요청으로 세지 않았다.
- 수정이 필요해진 뒤에만 `002dc1f`에서 `codex/band-verify`를 만들었다. 원시 증거와 화면은 저장소 밖에만 보관한다.

## 실제 게시 로그가 입증한 결과

08:35:42에 시작한 게시 작업은 08:41:24에 단일 `failed`로 끝났다. 생성 응답은 성공했고 응답 신원으로 글 주소를 저장했다. 주소 저장 완료는 응답 성공 로그 뒤 178ms이며 상세 검증 시작보다 앞선다. 피드 신원 탐색이나 게시 복구 도구는 사용하지 않았다. 실패한 원래 등록 기록에도 동일 글 주소가 남았다.

실제 상세 검증은 본문, 줄바꿈 158개, 사진 29장 전체 순서, 해시태그 2개를 통과했다. 링크는 실제 2개였지만 두 번째 목적지 비교가 실패했다. 앱 결과 화면은 성공 문구가 아니었다. 따라서 요구한 실제 `succeeded`와 `게시했습니다` 결과는 이번 실행에서 입증하지 못했다.

계획 본문에 괄호로 둘러싼 주소가 있었고, 예상 링크 정규식은 끝의 닫는 괄호까지 주소로 포함했다. 밴드가 만든 실제 링크는 그 괄호 직전에서 끝났으며 전체 본문 자체는 일치했다. 주소 길이는 예상보다 한 글자 짧고 그 차이는 마지막 닫는 괄호 한 글자임을 외부 읽기 증거로 확인했다.

## 수정과 같은 글 삭제

예상 링크를 비교할 때 짝이 없는 마지막 닫는 괄호만 제외한다. URL 내부의 균형 잡힌 괄호와 인코딩된 괄호는 보존한다. 전체 본문 비교는 그대로 수행하므로 본문이나 실제 목적지가 달라진 경우는 계속 실패한다.

상세 검증 실패 기록에 이미 생성된 주소가 있어도 삭제 자격이 없고 화면에 재시도가 나오는 문제가 함께 드러났다. 정확한 두 상세 검증 실패 사유와 저장된 밴드 주소가 있는 내 발행 기록에 기존 삭제 경로를 연결했다. 소유·본문·제목·시각 검증은 유지했다. 화면은 `확인 필요`로 표시하고 재시도 대신 등록 기록으로 이동하게 했다. 원래 작업 로그의 실패 상태는 보존한다.

회귀시험은 수정 전 5개 실패를 재현했고 수정 후 집중 시험 40개가 통과했다. 코드 커밋 `5029968`로 APK를 다시 빌드·덮어쓰기 설치했다. 새 게시 허용이나 제출은 없었다. 앱 등록 기록에서 해당 글만 선택하고 삭제 확인을 눌렀다. 삭제 작업은 08:45:03에 시작했고 생성 당시 신원·소유·본문·시각을 다시 확인한 뒤 피드 부재와 원래 URL의 삭제 응답을 검증했다. 앱의 읽기 전용 확인 화면을 닫은 뒤 삭제 작업은 단일 `succeeded`로 끝났고 기록은 `삭제함`으로 바뀌었다.
