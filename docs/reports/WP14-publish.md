# WP14 발행 방식 확인

2026-11-14 KST. 최신 `origin/main`을 fetch하고 `77d58cb`에서 `codex/publish-mode`를 만들었다. 이번 실제 계정 예외는 비공개 글 한 건의 발행·확인·삭제뿐이다. 밴드와 기존 실험 임시글 네 개는 조작하지 않았다.

블로그 발행은 임시저장·새 편집기 재열람 대조 뒤 공개 범위를 선택한다. 최종 버튼의 적중 요소와 선택 상태를 읽고, 마우스 이동 뒤 누름 직전에 다시 읽는다. 발행 작업의 한 번 열린 구간에서 신규 발행 요청 하나만 허용한다. 수정 요청과 반복 요청은 막는다. 비공개 요청은 실제 화면의 `openType` 라디오 이름·값과 실제 요청의 값이 하나로 대응해야 통과한다. 값의 의미를 숫자로 추측하지 않는다. 누락·중복·공개값·알 수 없는 구조는 `BLOG_PRIVATE_REQUEST_UNCONFIRMED`로 차단한다. 요청·응답 원문은 저장하지 않는다.

응답의 글 ID와 결과 화면 주소가 일치한 글만 읽는다. 제목·본문·문단·사진 수와 배치 순서·가격·출발일·골프장·태그를 기존 비교기로 대조하고, 비공개 표기도 확인한 뒤 같은 API 기록에 `published`와 최종 주소를 보낸다. 버튼 재입력은 금지하고 기록 실패는 동일 본문의 기록 전용 재시도만 허용한다. 임시저장 모드의 태그 포커스 검사·레이어 닫힘 확인·RabbitWrite/RabbitUpdate Fetch 차단은 유지했다.

일반 화면은 임시저장이 기본이며 발행 선택 때 전체공개/비공개와 시작 전 확인을 표시한다. 공개 범위 기본은 전체공개다. 디버그의 ‘실험 글 삭제’는 이번 실행 응답의 글 ID·주소와 현재 글이 같고 제목이 `[골투오토 실험]`으로 시작할 때만 삭제 버튼 한 번을 허용한다. 확인창이 다르거나 삭제 부재를 확인하지 못하면 중단한다. 삭제 확인 뒤 같은 API 기록을 `stopped`, `BLOG_TEST_POST_DELETED`, 빈 주소로 갱신한다. 서버에 `deleted` 상태가 없어 쓰는 실험 종료 표시다. 삭제 모듈·명령·버튼이 릴리스 번들에 없음을 시험했다.
