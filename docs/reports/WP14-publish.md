# WP14 발행 방식 확인

2026-11-14 KST, `codex/publish-mode`, 초안 PR #17. 이번 후속 작업에서 실기기 발행·밴드·임시저장 추가 실행은 하지 않았다.

## 현재 상태

11:11에 디버그 삭제를 한 번 시작했으나 `SURFACE_READ_FAILED_OR_SIDE_EFFECT`로 중단됐다. 중단 뒤 읽기 전용 확인에서도 이번 표식의 글, 비공개 표시, 사진 13장이 남아 있었다. 삭제나 부재 확인에 성공했다고 기록하지 않았다. 다른 삭제 경로와 재시도, 추가 기기 입력은 중단했다. API는 기존 `failed` / `BLOG_PUBLISH_RESPONSE_UNCONFIRMED` 상태다. `BLOG_TEST_POST_DELETED` 갱신은 보내지 않았다.

소유자는 이번 글의 `[골투오토 실험]`, `WP14 private-once`, 비공개를 확인한 뒤 네이버 웹/앱에서 그 글만 직접 삭제하고 글 주소와 목록의 부재를 확인해야 한다. 디버그 복구 문맥은 한 번 사용한 상태라 다시 삭제를 시도하지 않는다.

## 삭제 전 대조와 증거

- 제목 원문: 일치.
- 사진: API 사진 바이트의 식별값으로 13장과 순서 일치.
- 가격 3개·출발일 3개·골프장 값: 일치. 본문 문단도 공백 정리 후 일치.
- 전체 글자 비교: 불일치. 발행 화면에서 기본 해시태그 1개를 읽지 못해 `text`, `characters`가 달랐다. 전체 검증 통과로 처리하지 않았다.
- 글 화면 URL 형태만 기록했다: 바깥 `/N/N`, 내부 `/PostView.naver?blogId=N&Redirect=N&logNo=N&categoryNo=N&isAfterWrite=N&isMrblogPost=N&isHappyBeanLeverage=N&contentLength=N`.

이전 발행 응답 원문이나 구조는 확보하지 못했다. URL 형태만으로 당시 파싱 실패 원인을 단정할 수 없다. 응답을 연구하려고 다시 발행하지 않았다. 구조 증거는 저장소 밖 `../runs/wp14-cleanup-*.json`과 앱의 디버그 결과에만 뒀다.

## 변경

디버그 삭제는 응답 식별자가 없어도 같은 글 화면에서 제목 접두사·이번 실행 표식·정확한 제목·비공개·네이버 글 URL·사진 13장을 함께 검사한다. 하나라도 빠지거나 중복·충돌하면 거부한다. 다른 글·다른 실행·공개 글은 거부한다. 삭제 시도는 한 번으로 제한하며, 같은 글에서 나온 예상 삭제 확인창만 허용한다. 글 URL의 삭제 안내와 글 목록의 부재가 모두 확인돼야 같은 API 기록을 `stopped` / `BLOG_TEST_POST_DELETED`로 바꾼다.

교체 설치에 필요한 이번 실패 기록·상품 해시·사진 식별값·화면 주소는 앱 전용 디버그 문맥으로 전달했다. 인증 자료를 넣지 않았고, API의 기존 실패 기록과 다시 대조했다. 설치 전 연결·Awake·display ON·현재 창·전면 Activity를 교차 확인했다. `adb install -r`로 로그인 상태를 유지했다. 입력 전 앱의 전면·창 포커스·화면 켜짐과 편집기 포커스·적중 대상을 검사한다. 깨우기·잠금 해제·다른 앱 조작은 하지 않았다.

로컬 합성 삭제 시험에서 목록 검사 안의 URL 생성이 읽기 전용 평가에 거부되는 문제를 수정했다. 주소 문자열만 읽고 Node에서 해석한다. 중단된 실기기에는 수정본을 재설치하거나 재시도하지 않았다. 실기기 오류의 정확한 발생 지점은 확정하지 못했다.

발행 식별은 기존에 이해하는 응답, 발행 뒤 이동한 URL, 방금 발행한 제목과 정확히 같은 글 화면을 독립적인 근거로 쓴다. 하나의 근거가 명확하면 식별할 수 있지만 근거끼리 충돌하면 중단한다. 알 수 없는 응답 구조를 추측하지 않는다. 최종 제목·내용·사진·숫자 대조와 한 번 발행 제한은 유지한다.

디버그 응답 기록은 구조 필드 이름·타입·길이만 남긴다. 식별자와 모든 값은 길이로 바꾸고, 알 수 있는 구조 이름 외의 키도 길이만 남긴다. 삭제·복구·응답 구조 기록은 릴리스 번들에서 제외한다. 새 발행 식별 경로는 합성 시험만 통과했으며, 향후 별도 승인 발행 전까지 실서비스 미검증이다.
